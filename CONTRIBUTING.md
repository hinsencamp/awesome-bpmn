# Contributing to Awesome BPMN

Thank you for contributing! Here are a few guidelines:

## Adding a Resource

1. Fork the repository
2. Add your resource to the most specific applicable section
3. Use the format: `[Name](URL) - Brief description.`
4. For open-source projects, include the GitHub link and star count (round to nearest 100)
5. Keep descriptions to one or two lines
6. Submit a pull request

## Quality Standards

Resources should be:

- **Relevant** to developers working with BPMN 2.0
- **Active** and maintained (no abandoned projects unless historically significant)
- **Useful** - add a description that explains what the tool does and why a developer would use it

## Sections

- **Process Knowledge Platforms** - Tools that combine modeling with collaboration, governance, and organizational knowledge management
- **Diagramming Tools** - General-purpose drawing tools that happen to have BPMN shapes
- **Libraries** - Code you embed in your own application
- **Execution Engines** - Runtimes that execute BPMN process definitions
- **AI + BPMN** - Tools using AI/LLMs to generate, edit, or understand BPMN
- **Converters** - Tools that transform between formats
- **Learning Resources** - Courses, references, books, articles

When in doubt about which section fits, open an issue to discuss.

## What We Don't Include

- Generic project management or task tracking tools
- Workflow tools that don't support BPMN notation
- Paid tools without a free tier or trial (unless they're industry-standard)
